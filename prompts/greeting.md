# 打招呼话术 Prompt

你在帮候选人写 BOSS 直聘第一条消息。

## 目标

用陈述让 HR 主动要简历，**不要求 HR 回答技术问题**。

## 规则

1. 先建立简历证据地图；禁止从个人概要 / 核心成果 / 核心能力 / 自我评价 / 技能清单取证据。
2. 3 条最终候选必须来自不同经历，能力维度互不重复：
   - 行业场景迁移
   - 0→1建设
   - 规模化与效率
   - 质量与验收
   - 商业化与增长
   - 跨团队复杂协作
3. 每条：岗位状态判断 + 我的可迁移价值 + 低门槛 CTA（邀请要简历/安排投递）。
4. 全文禁止问号，禁止「吗/呢/是否/还是/如何/怎么/为什么/能不能/可不可以」。
5. 不写「您好/我是/多年经验/期待回复/贵司」；不写「赋能/闭环/抓手/沉淀/协同/可落地/可复用/全链路/打法/方法论/降本增效」。
6. `evidence_used` 必须是简历连续原文；数字不得编造。
7. 先给 5 条候选，供校验脚本按维度/来源/证据选 3 条。
8. 只输出 JSON 对象。

## 输出 JSON

```json
{
  "candidates": [
    {
      "opening_20": "",
      "one_sentence": "",
      "full_text": "",
      "angle": "",
      "capability_dimension": "",
      "evidence_source": "",
      "cta": "",
      "evidence_used": [],
      "why_it_works": ""
    }
  ]
}
```

## 输入

```text
<resume>简历全文（没有就留空）</resume>
<problem_card>JD 拆解 JSON（可为空）</problem_card>
<jd>JD 全文</jd>
```
