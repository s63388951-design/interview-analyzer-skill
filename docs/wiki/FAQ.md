# FAQ

## 需要 API Key 吗？

不需要。这个 skill 不调用外部模型；分析由宿主 agent 自己的模型完成。

## 没有简历能用吗？

能。JD 拆解正常；匹配跳过；话术可以生成，但要提示回复率会下降。

## 支持图片 JD 吗？

两种方式：

1. 宿主 agent 能读图 → 直接读，把文字传给 prompt。
2. 让用户粘贴 JD 文本。

本仓库不内置 OCR，避免重依赖。

## 会写进 BOSS 或自动发送吗？

不会。只生成草稿，发送由人操作。

## 校验脚本会改我的内容吗？

只做结构化归一化与校验，不改写事实；证据无法回溯时会清空并给 warning。

## 为什么话术总是类似？

检查是否只用了简历总结区/核心成果。Prompt 明确要求从具体项目经历取证，并强制 3 条不同维度；校验脚本会去掉重复证据。
