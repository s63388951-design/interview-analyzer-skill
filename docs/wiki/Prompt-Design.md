# Prompt Design

## JD

目标不是“总结 JD”，而是回答“为什么现在招、要解决什么”。

- 表层问题 vs 真实问题
- 问题类型：止血 / 建设 / 转型 / 补位
- 问题—症状—代价
- 为什么现在招 + 置信度

## 匹配

- 3 条优势，每条必须有简历原文证据
- 缺口直说，不用“可快速学习”糊过去
- 评分由脚本重算，避免模型算术错误

## 话术

- 陈述式，不提问
- 3 条来自不同经历、不同能力维度
- 禁止从简历总结区取证据
- CTA 只邀请要简历/安排投递，不承诺面试

## 为什么不用固定模板

固定模板会让 HR 一眼看出群发。Prompt 只规定信息结构和红线，具体措辞由宿主模型按岗位/简历生成。
