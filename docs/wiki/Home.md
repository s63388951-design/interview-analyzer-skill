## 最快用法

1. `git clone https://github.com/s63388951-design/interview-analyzer-skill.git`
2. 把整个目录复制到宿主 skill 目录
3. 让 agent 读取 `SKILL.md`
4. 用 `prompts/` 分析，用 `scripts/validate.py` 校验

不需要 API Key。分析由宿主 agent 自己的模型完成。
